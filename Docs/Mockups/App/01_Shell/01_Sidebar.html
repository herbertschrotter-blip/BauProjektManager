Klappbare Sidebar (BPM-067)

Chevron oben oder Doppelklick auf den Titel schaltet zwischen Zustand A (220px, Emoji + Text, Badge neben dem Text) und Zustand B (56px, nur Emoji mit Tooltip, Badge als Ecke am Icon) um. Default beim ersten Start: aufgeklappt. Der Zustand wird gerätelokal gemerkt (DeviceSettings.UiLayout.SidebarCollapsed).

Aktives Modul: bg-active + text-bright + 3px accent-primary-Balken links. Hover: bg-hover. Post-V1-Module: opacity .35, nicht klickbar — werden später über Ansichtsprofile ein-/ausgeblendet (Architektur Kap. 1.4).

Emoji-Quellen: 📁 ⚙ 🛠 👤 aus Icons.xaml · 📷 ⏱ 📓 📧 🌤 📄 aus dem Modulbaum der Architektur · 🏠 🧮 📋 🗺 🤖 neu (beim WPF-Umbau in Icons.xaml anlegen). Segoe Fluent Icons bleiben eine getrennte Entscheidung.

Einstellungen und Dev Tools stehen unten (Entscheidung Herbert, Teil 52). Home ganz oben übernimmt die Dashboard-Rolle.
