Wie wird der Index (Revision) erkannt?
Aus Dateiname
Index wird aus einem Segment im Dateinamen gelesen (z.B. A, B, C)
Kein Index
Dokument hat keinen Index. Versionen werden per MD5-Hash erkannt.
Aus Plankopf POST-V1
Index wird aus dem PDF-Plankopf gelesen. Noch nicht verfügbar.
Index-Modus
Optional (Erstausgabe kann ohne Index sein)
Pflicht (Jedes Dokument muss einen Index haben)
Gross-/Kleinschreibung ignorieren (A = a)
⚠ In Schritt 2 wurde kein Index-Segment zugewiesen. Gehe zurück und weise einem Segment den Typ Index zu, oder wähle Kein Index.
